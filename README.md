## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest stable)
- Dart SDK

### Build & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/shayann07/medicare_app_flutter.git
   cd medicare_app_flutter
   ```
2. Install packages:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
